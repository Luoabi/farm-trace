# 🧪 快速测试指南

## 准备工作

### 1. 启动后端服务
```bash
cd Backend/xichang-interface
mvn spring-boot:run
```

### 2. 配置微信开发者工具
- 打开微信开发者工具
- 点击右上角"详情"
- 勾选"不校验合法域名..."
- 点击"编译"

---

## 完整测试流程

### 第1步：注册账号 ✅

1. 打开小程序，看到登录页
2. 点击"立即注册"
3. 填写信息：
   ```
   真实姓名：张三
   手机号：13900139000
   密码：123456
   确认密码：123456
   ```
4. 点击"注册"
5. 看到"注册成功"提示
6. 自动返回登录页

**预期结果：** ✅ 注册成功

---

### 第2步：登录 ✅

1. 在登录页输入：
   ```
   手机号：13900139000
   密码：123456
   ```
2. 点击"登录"
3. 看到"登录成功"提示
4. 自动跳转到首页

**预期结果：** ✅ 登录成功，进入首页

---

### 第3步：浏览商品 ✅

1. 在首页看到商品列表
2. 尝试搜索商品（输入关键词）
3. 尝试切换分类（蔬菜、水果等）
4. 下拉刷新列表
5. 上拉加载更多

**预期结果：** ✅ 商品列表正常显示和筛选

---

### 第4步：查看商品详情 ✅

1. 点击任意商品
2. 进入商品详情页
3. 查看商品信息
4. 修改购买数量（+/-）

**预期结果：** ✅ 商品详情正常显示

---

### 第5步：加入购物车 ✅

1. 在商品详情页点击"加入购物车"
2. 看到"已加入购物车"提示
3. 返回首页
4. 再次点击其他商品的购物车图标
5. 点击底部"购物车"标签

**预期结果：** ✅ 购物车中有2个商品

---

### 第6步：管理购物车 ✅

1. 在购物车页面：
   - 选择/取消选择商品
   - 修改商品数量
   - 删除商品
   - 全选/取消全选
2. 查看总价是否正确计算

**预期结果：** ✅ 购物车操作正常

---

### 第7步：添加收货地址 ✅

1. 点击底部"我的"标签
2. 点击"收货地址"
3. 点击"+ 新增地址"
4. 填写地址信息：
   ```
   收货人：张三
   手机号：13900139000
   所在地区：四川省 凉山彝族自治州 西昌市
   详细地址：航天大道123号
   设为默认：开启
   ```
5. 点击"添加"

**预期结果：** ✅ 地址添加成功

---

### 第8步：提交订单 ✅

1. 返回购物车
2. 选择要购买的商品
3. 点击"结算"
4. 在确认订单页：
   - 确认收货地址
   - 确认商品信息
   - 输入订单备注（可选）
5. 点击"提交订单"

**预期结果：** ✅ 订单提交成功，跳转到订单详情

---

### 第9步：查看订单 ✅

1. 在订单详情页查看：
   - 订单状态
   - 收货信息
   - 商品清单
   - 订单信息
   - 价格明细
2. 点击"复制"复制订单号
3. 返回，点击底部"订单"标签
4. 查看订单列表
5. 切换不同状态筛选

**预期结果：** ✅ 订单信息正常显示

---

### 第10步：取消订单 ✅

1. 在订单列表点击订单
2. 进入订单详情
3. 点击"取消订单"
4. 确认取消
5. 看到"订单已取消"提示
6. 订单状态变为"已取消"

**预期结果：** ✅ 订单取消成功

---

## 常见问题测试

### 1. 网络异常
- [ ] 关闭后端，尝试登录
- [ ] 应该显示"网络请求失败"

### 2. 表单验证
- [ ] 输入错误格式手机号
- [ ] 输入不一致的密码
- [ ] 应该显示相应错误提示

### 3. 空状态
- [ ] 查看空购物车
- [ ] 查看空地址列表
- [ ] 应该显示友好的空状态提示

### 4. 边界情况
- [ ] 购买数量超过库存
- [ ] 未选择地址提交订单
- [ ] 应该有相应的错误提示
