# 西昌农产品溯源小程序开发计划

## 一、项目概述

### 项目名称
西昌农产品溯源小程序

### 技术栈
- 框架：微信小程序原生 + TypeScript
- 渲染引擎：Skyline
- 组件框架：glass-easel
- 后端接口：已完成（Spring Boot）

### 核心功能
1. 商品浏览和购买
2. 订单管理
3. 收货地址管理
4. 溯源查询（扫码）
5. 个人中心

---

## 二、后端接口清单

### ✅ 已完成的接口（100%）

#### 1. 用户认证
```
POST /api/register          # 注册
POST /api/login             # 登录
```

#### 2. 商品管理
```
POST /api/product/list                      # 商品列表（分页）
GET  /api/product/detail/{id}               # 商品详情
GET  /api/product/list-by-category/{category}  # 分类查询
```

#### 3. 订单管理
```
POST   /api/order/create                    # 创建订单
POST   /api/order/list-by-customer          # 我的订单
GET    /api/order/detail/{id}               # 订单详情
PUT    /api/order/cancel/{id}               # 取消订单
PUT    /api/order/update-status/{id}        # 更新状态（确认收货）
```

#### 4. 收货地址
```
GET    /api/user/address/list               # 地址列表
POST   /api/user/address/create             # 添加地址
PUT    /api/user/address/update/{id}        # 更新地址
DELETE /api/user/address/delete/{id}        # 删除地址
PUT    /api/user/address/set-default/{id}   # 设置默认
GET    /api/user/address/default            # 获取默认地址
```

#### 5. 溯源查询
```
GET /api/trace/batch/{batchNumber}          # 批次溯源信息
GET /api/trace/verify/{txHash}              # 区块链验证
```

## 六、开发规范

### 1. 命名规范
- 文件名：kebab-case（如：product-detail.ts）
- 变量名：camelCase（如：productList）
- 常量名：UPPER_SNAKE_CASE（如：API_BASE_URL）
- 类型名：PascalCase（如：ProductInfo）

### 2. 代码规范
- 使用 TypeScript 严格模式
- 所有接口调用必须有错误处理
- 使用 async/await 处理异步操作
- 统一使用 wx.showToast 显示提示信息

### 3. 注释规范
```typescript

 * 获取商品列表
```
