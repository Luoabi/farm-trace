## 🛠️ 调试方法

### 1. 查看控制台日志

打开微信开发者工具的调试器，查看 Console 面板：

```javascript
// 登录时会输出：
"请求响应:" {statusCode: 200, data: {...}}
"登录响应:" {token: "...", user: {...}}
"用户信息保存成功:" {id: "1", username: "..."}

// 注册时会输出：
"请求响应:" {statusCode: 200, data: {...}}
"注册响应:" {id: "1", username: "..."}
```

### 2. 查看网络请求

在调试器的 Network 面板：

```
POST http://localhost:8080/api/login
Request Headers:
  Content-Type: application/json
Request Payload:
  {username: "13800138000", password: "123456"}
Response:
  {token: "...", user: {...}}
```

### 3. 查看存储数据

在调试器的 Storage 面板：

```
token: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
userInfo: "{\"id\":\"1\",\"username\":\"13800138000\",\"realName\":\"张三\",...}"
```

### 4. 手动清除登录状态

在 Console 面板执行：

```javascript
// 清除所有存储
wx.clearStorageSync()

// 或只清除登录信息
wx.removeStorageSync('token')
wx.removeStorageSync('userInfo')
```

## ⚠️ 常见问题

### Q1: 点击登录后没有反应

**可能原因：**
- 后端服务未启动
- API 地址配置错误
- 网络请求被拦截

**解决方法：**
1. 检查后端服务是否运行在 `http://localhost:8080`
2. 查看控制台是否有错误信息
3. 检查 Network 面板的请求状态

### Q2: 提示"网络请求失败"

**可能原因：**
- 后端服务未启动
- 端口号错误
- 防火墙拦截

**解决方法：**
1. 启动后端服务：`cd Backend/xichang-interface && mvn spring-boot:run`
2. 确认服务运行在 8080 端口
3. 浏览器访问 `http://localhost:8080` 测试

### Q3: 登录成功但跳转失败

**可能原因：**
- 首页路径配置错误
- tabBar 配置问题

**解决方法：**
1. 检查 app.json 中的 tabBar 配置
2. 确认 pages/index/index 在 pages 数组中
3. 查看控制台错误信息

### Q4: Token 未保存

**可能原因：**
- 后端返回的数据格式不匹配
- saveUserInfo 函数处理错误

**解决方法：**
1. 查看控制台的"登录响应"日志
2. 检查响应数据是否包含 token 字段
3. 查看 Storage 面板确认是否保存

### Q5: 提示"用户名或密码错误"

**可能原因：**
- 密码确实错误
- 用户不存在
- 后端验证逻辑问题

**解决方法：**
1. 确认输入的手机号和密码正确
2. 先注册新用户再登录
3. 检查后端数据库中的用户数据
