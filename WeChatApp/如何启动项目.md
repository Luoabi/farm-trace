# 🚀 如何启动西昌农产品溯源小程序

## 前置条件

### 1. 安装微信开发者工具
- 下载地址：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
- 安装并打开微信开发者工具

### 2. 启动后端服务
确保后端服务正常运行：
```bash
# 进入后端项目目录
cd Backend/xichang-interface

# 启动 Spring Boot 应用
mvn spring-boot:run

# 或者使用 IDE 直接运行 XichangInterfaceApplication
```

后端服务应该运行在：`http://localhost:8080`

### 3. 准备测试数据
确保数据库中有：
- ✅ 测试用户（或通过小程序注册）
- ✅ 商品数据（至少几个商品用于测试）
- ✅ 商品分类数据

### 步骤 2：配置后端地址（可选）

如果后端地址不是 `http://localhost:8080`，需要修改配置：


## 常见问题

### Q1: 编译失败
**A:** 检查以下几点：
- TypeScript 配置是否正确
- 所有文件是否都已创建
- 微信开发者工具版本是否最新

### Q2: 登录失败
**A:** 检查：
- 后端服务是否启动
- 后端地址配置是否正确
- 网络连接是否正常
- 查看控制台错误信息

### Q3: 商品列表为空
**A:** 检查：
- 数据库中是否有商品数据
- 后端接口是否正常
- 查看网络请求是否成功

### Q4: 扫码功能无法使用
**A:** 
- 扫码功能需要在真机上测试
- 模拟器不支持扫码功能
- 使用真机调试功能

### Q5: 页面显示"开发中"
**A:** 
- 这是正常的，部分页面还在开发中
- 当前已完成的页面：
  - ✅ 登录页
  - ✅ 注册页
  - ✅ 首页
  - ✅ 购物车
  - ✅ 订单列表
  - ✅ 个人中心

## 调试技巧

### 1. 查看控制台日志
在微信开发者工具中：
- 点击"调试器"标签
- 查看 Console 面板
- 所有 console.log 输出都会显示在这里

### 2. 查看网络请求
在调试器中：
- 点击 Network 标签
- 查看所有 API 请求
- 检查请求参数和响应数据

### 3. 查看存储数据
在调试器中：
- 点击 Storage 标签
- 查看 localStorage 中的数据
- 可以手动清除缓存

### 4. 真机调试
1. 点击工具栏的"真机调试"
2. 使用微信扫码
3. 在真机上测试扫码等功能

## 开发建议

### 1. 开发流程
1. 先在模拟器中开发和测试
2. 功能完成后在真机上测试
3. 修复真机上的问题

### 2. 代码规范

- 添加必要的注释

### 3. 测试建议
- 测试所有页面跳转
- 测试所有表单验证
- 测试网络异常情况
