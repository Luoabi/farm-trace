# 登录功能测试指南

## 测试步骤

### 1. 准备测试数据

确保后端数据库中有测试用户，或者先注册一个新用户。

### 2. 测试注册功能

1. 打开小程序，点击"立即注册"
2. 填写信息：
   - 真实姓名：测试用户
   - 手机号：13800138000
   - 密码：123456
   - 确认密码：123456
3. 点击"注册"按钮
4. 预期结果：
   - 显示"注册中..."加载提示
   - 注册成功后显示成功提示
   - 自动返回登录页

### 3. 测试登录功能

1. 在登录页输入：
   - 手机号：13800138000
   - 密码：123456
2. 点击"登录"按钮
3. 预期结果：
   - 显示"登录中..."加载提示
   - 登录成功后显示成功提示
   - 自动跳转到首页

### 4. 测试表单验证

#### 登录页验证
- 不输入手机号，点击登录 → 提示"请输入手机号"
- 输入错误格式手机号（如：123），点击登录 → 提示"手机号格式不正确"
- 不输入密码，点击登录 → 提示"请输入密码"
- 输入少于6位密码，点击登录 → 提示"密码长度不能少于6位"

#### 注册页验证
- 不输入真实姓名 → 提示"请输入真实姓名"
- 不输入手机号 → 提示"请输入手机号"
- 输入错误格式手机号 → 提示"手机号格式不正确"
- 不输入密码 → 提示"请输入密码"
- 密码长度不符合要求 → 提示"密码长度为6-20位"
- 两次密码不一致 → 提示"两次密码输入不一致"

### 5. 测试错误处理

#### 网络错误
1. 关闭后端服务
2. 尝试登录
3. 预期结果：显示"网络请求失败"

#### 用户名或密码错误
1. 输入错误的密码
2. 点击登录
3. 预期结果：显示后端返回的错误信息

#### 用户已存在
1. 使用已注册的手机号注册
2. 预期结果：显示"用户已存在"或类似错误

### 6. 测试登录状态

1. 登录成功后，查看 Storage
   - 应该有 `token` 字段
   - 应该有 `userInfo` 字段
2. 关闭小程序重新打开
3. 预期结果：
   - 如果已登录，直接进入首页
   - 如果未登录，显示登录页

## 调试技巧

### 1. 查看控制台日志
在微信开发者工具中打开调试器，查看 Console 面板：
- 登录请求的 URL
- 请求参数
- 响应数据
- 错误信息

### 2. 查看网络请求
在调试器的 Network 面板：
- 查看请求的完整信息
- 检查请求头（是否包含 token）
- 检查响应状态码
- 检查响应数据格式

### 3. 查看存储数据
在调试器的 Storage 面板：
- 查看 `token` 的值
- 查看 `userInfo` 的内容
- 手动清除存储测试未登录状态

### 4. 断点调试
在代码中添加 `debugger` 或使用开发者工具的断点功能：
```typescript
async handleLogin() {
  debugger; // 在这里暂停
  const { phone, password } = this.data;
  // ...
}
```

## 常见问题

### Q1: 登录后跳转失败
**原因：** 首页不在 tabBar 中或路径错误
**解决：** 检查 app.json 中的 tabBar 配置

### Q2: Token 未保存
**原因：** 后端返回的数据格式不匹配
**解决：** 检查 `saveUserInfo` 函数的数据处理逻辑

### Q3: 提示"请先登录"
**原因：** Token 过期或未正确保存
**解决：** 清除存储重新登录

### Q4: 网络请求失败
**原因：** 后端服务未启动或地址配置错误
**解决：** 
- 检查后端服务是否运行
- 检查 `utils/config.ts` 中的 API_BASE_URL

Content-Type: application/json

请求体：
{
  "username": "13800138000",
  "password": "123456",
  "realName": "测试用户",
  "phone": "13800138000",
  "role": "CUSTOMER"

响应（成功）：

  "message": "注册成功",
