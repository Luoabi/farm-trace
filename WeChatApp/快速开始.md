# 快速开始指南

## 一、项目说明

这是西昌农产品溯源小程序项目，使用微信小程序原生框架 + TypeScript 开发。

### 技术栈
- 微信小程序原生框架
- TypeScript
- Skyline 渲染引擎
- glass-easel 组件框架

### 后端接口
- 基础地址：`http://localhost:8080/api`
- 接口文档：查看 `开发计划.md`

## 二、开发环境

### 1. 安装微信开发者工具
下载地址：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

1. 打开微信开发者工具
2. 选择"导入项目"
3. 选择 `WeChatApp` 目录

创建 `miniprogram/api/` 目录，并添加以下文件：

#### 1. user.ts - 用户接口
```typescript
import { post } from '../utils/request';

// 注册
export function register(data: {
  username: string;
  password: string;
  realName: string;
  phone: string;
}) {
  return post('/register', {
    ...data,
    role: 'CUSTOMER'
  });
}

// 登录
export function login(data: {
  username: string;
  password: string;
}) {
  return post('/login', data);
}
```

#### 2. product.ts - 商品接口

#### 3. order.ts - 订单接口
```typescript
import { get, post, put } from '../utils/request';

// 创建订单

  return post('/order/create', data);
```

### 第二步：创建登录页面

创建 `pages/login/` 目录，参考以下代码：

#### login.wxml
```xml
<view class="container">
  <view class="logo">
    <image src="/images/logo.png" mode="aspectFit"></image>
    <text class="title">西昌农产品溯源</text>
  </view>

  <view class="form">
    <view class="form-item">
      <input 
        type="text" 
        placeholder="请输入手机号" 
        value="{{phone}}"
        bindinput="onPhoneInput"
      />
    </view>
    <view class="form-item">
      <input 
        type="password" 
        placeholder="请输入密码" 
        value="{{password}}"
        bindinput="onPasswordInput"
      />
    </view>
    <button class="btn-login" bindtap="handleLogin">登录</button>
    <view class="register-link">
      <text>还没有账号？</text>
      <text class="link" bindtap="goToRegister">立即注册</text>
    </view>
  </view>
</view>
```

#### login.ts
```typescript
import { login } from '../../api/user';
import { saveUserInfo } from '../../utils/auth';

Page({
  data: {
    phone: '',
    password: ''
  },

  onPhoneInput(e: any) {
    this.setData({ phone: e.detail.value });
  },

  onPasswordInput(e: any) {
    this.setData({ password: e.detail.value });
  },

  async handleLogin() {
    const { phone, password } = this.data;

    if (!phone || !password) {
      wx.showToast({
        title: '请输入手机号和密码',
        icon: 'none'
      });
      return;
    }

    try {
      wx.showLoading({ title: '登录中...' });
      
      const res = await login({
        username: phone,
        password: password
      });

      wx.hideLoading();

      // 保存用户信息
      saveUserInfo(res);

      wx.showToast({
        title: '登录成功',
        icon: 'success'
      });

      setTimeout(() => {
        wx.switchTab({ url: '/pages/index/index' });
      }, 1500);
    } catch (error) {
      wx.hideLoading();
      console.error('登录失败:', error);
    }
  },

  goToRegister() {
    wx.navigateTo({ url: '/pages/register/register' });
  }
});
```

## 七、常见问题

### 1. 请求失败
- 检查后端服务是否启动
- 检查 API 地址是否正确
- 检查网络连接

### 2. 登录失败
- 检查用户名和密码是否正确
- 检查后端接口是否正常
- 查看控制台错误信息

### 3. 页面跳转失败
- 检查页面路径是否正确
- 检查页面是否在 app.json 中注册
