# 域名配置说明

## 问题描述

小程序报错：`request:fail url not in domain list`

这是因为微信小程序对网络请求有严格的域名限制。

---

## 解决方案

### 方案1：开发环境 - 关闭域名校验（推荐）✅

已在 `project.config.json` 中添加配置：

```json
{
  "setting": {
    "urlCheck": false
  }
}
```

**操作步骤：**

1. 打开微信开发者工具
2. 点击右上角"详情"按钮
3. 在"本地设置"标签页中
4. 勾选"不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书"

![设置截图](https://developers.weixin.qq.com/miniprogram/dev/image/devtools2/setting.png)

**注意：** 这个设置只在开发环境有效，正式版本必须配置合法域名。

---

### 方案2：生产环境 - 配置合法域名

#### 步骤1：准备 HTTPS 域名

小程序要求必须使用 HTTPS 协议，需要：
- 一个已备案的域名
- SSL 证书（可以使用免费的 Let's Encrypt）
- 后端服务部署到该域名

例如：`https://api.yourdomain.com`

#### 步骤2：在小程序后台配置

1. 登录[微信公众平台](https://mp.weixin.qq.com/)
2. 进入"开发" -> "开发管理" -> "开发设置"
3. 找到"服务器域名"
4. 点击"修改"
5. 在"request合法域名"中添加：`https://api.yourdomain.com`

![配置截图](https://developers.weixin.qq.com/miniprogram/dev/image/mina-config.png)

#### 步骤3：修改小程序配置

修改 `miniprogram/utils/config.ts`：

```typescript
// 开发环境
// export const API_BASE_URL = 'http://localhost:8080/api';

// 生产环境
export const API_BASE_URL = 'https://api.yourdomain.com/api';
```

## 常见问题

### Q1: 为什么开发环境可以用 HTTP？

**A:** 开发环境关闭了域名校验，可以使用 HTTP 和 localhost。但正式版本必须使用 HTTPS。

### Q2: 如何获取免费的 SSL 证书？

**A:** 可以使用：
- Let's Encrypt（免费）
- 阿里云/腾讯云提供的免费证书
- Cloudflare（免费）

### Q3: 域名配置后多久生效？

**A:** 通常立即生效，最多等待几分钟。

### Q4: 可以配置多个域名吗？

**A:** 可以，在小程序后台可以配置多个合法域名。

### Q5: 开发环境设置不生效？

**A:** 检查：
1. 是否勾选了"不校验合法域名"
2. 是否重新编译了项目
3. 是否清除了缓存

## 测试步骤

### 1. 确认配置已生效

1. 打开微信开发者工具
2. 点击右上角"详情"
3. 查看"本地设置"
4. 确认已勾选"不校验合法域名..."

### 2. 重新编译项目

1. 点击"编译"按钮
2. 或使用快捷键 `Ctrl + B`（Windows）/ `Cmd + B`（Mac）

### 3. 测试登录功能

1. 打开登录页
2. 输入手机号和密码
3. 点击登录
4. 查看控制台是否还有域名错误

### 4. 查看网络请求

1. 打开调试器
2. 切换到 Network 标签
3. 查看请求是否成功发送到 `http://localhost:8080/api/login`
