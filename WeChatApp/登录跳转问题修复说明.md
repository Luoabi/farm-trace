# 登录跳转问题修复说明

## 问题描述

登录成功后跳转到首页，但立即又跳回登录页。

## 原因分析

### 问题1：后端未返回 token
后端的 `UserResponse` 没有 `token` 字段，导致：
1. `saveUserInfo()` 无法保存 token
2. `checkLogin()` 检查 token 时返回 false
3. 首页检测到未登录，跳回登录页

### 问题2：时序问题
登录页跳转到首页时，`saveUserInfo()` 可能还没完成，首页的 `onLoad()` 就开始检查登录状态。

## 已实施的修复

### 修复1：优化 checkLogin() ✅

**文件：** `WeChatApp/miniprogram/utils/auth.ts`

**修改：** 不再强制要求 token，只检查用户信息

```typescript
export function checkLogin(): boolean {
  const userInfo = wx.getStorageSync(USER_INFO_KEY);
  // 只要有用户信息就认为已登录
  return !!userInfo;
}
```

### 修复2：优化 saveUserInfo() ✅

**文件：** `WeChatApp/miniprogram/utils/auth.ts`

**修改：** 
1. 处理多种后端响应格式
2. 如果没有 token，使用用户ID作为临时标识
3. 添加详细的日志输出

```typescript
export function saveUserInfo(data: any): void {
  try {
    console.log('开始保存用户信息，原始数据:', data);
    
    let userInfo: any;
    let token: string | undefined;
    
    // 处理多种响应格式
    if (data.code !== undefined && data.data) {
      userInfo = data.data;
      token = data.data.token;
    } else if (data.id && data.username) {
      userInfo = data;
      token = data.token;
    } else if (data.user) {
      userInfo = data.user;
      token = data.token;
    } else {
      userInfo = data;
      token = data.token;
    }
    
    // 保存 token 或使用临时标识
    if (token) {
      wx.setStorageSync(TOKEN_KEY, token);
    } else {
      console.warn('警告：后端未返回 token');
      if (userInfo.id) {
        wx.setStorageSync(TOKEN_KEY, `temp_${userInfo.id}`);
      }
    }
    
    // 保存用户信息
    wx.setStorageSync(USER_INFO_KEY, JSON.stringify(userInfo));
    
    console.log('用户信息保存成功:', userInfo);
  } catch (error) {
    console.error('保存用户信息失败:', error);
    throw error;
  }
}
```

### 修复3：延迟检查登录状态 ✅

**文件：** `WeChatApp/miniprogram/pages/index/index.ts`

**修改：** 
1. 延迟100ms检查登录状态
2. 在 `onShow()` 中也检查登录状态
3. 添加日志输出

```typescript
onLoad() {
  // 延迟检查，确保数据已保存
  setTimeout(() => {
    this.checkLogin();
  }, 100);
  this.loadProducts();
},

onShow() {
  // 每次显示页面时也检查
  this.checkLogin();
},

checkLogin() {
  if (!isLoggedIn()) {
    console.log('未登录，跳转到登录页');
    wx.redirectTo({ url: '/pages/login/login' });
  } else {
    console.log('已登录');
  }
}
```

### 建议2：实现真正的 JWT Token

添加依赖：
```xml
<dependency>
    <groupId>io.jsonwebtoken</groupId>
    <artifactId>jjwt</artifactId>
    <version>0.9.1</version>
</dependency>
```

创建 JwtUtil：
```java
public class JwtUtil {
    private static final String SECRET = "your-secret-key";
    private static final long EXPIRATION = 7 * 24 * 60 * 60 * 1000; // 7天
    
    public static String generateToken(String userId) {
        return Jwts.builder()
            .setSubject(userId)
            .setIssuedAt(new Date())
            .setExpiration(new Date(System.currentTimeMillis() + EXPIRATION))
            .signWith(SignatureAlgorithm.HS512, SECRET)
            .compact();
    }
}
```
