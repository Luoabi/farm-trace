### 3. UserServiceImpl.java - getUserPermissions() ✅
**文件：** `Backend/xichang-interface/src/main/java/org/xingchang/xichanginterface/service/impl/UserServiceImpl.java`

**修改：** 添加 CUSTOMER 角色权限

```java
/**
 * 根据角色获取权限列表
 */
private List<String> getUserPermissions(String role) {
    List<String> permissions = new ArrayList<>();

    switch (role) {
        case "SUPER_ADMIN":
            permissions.add("user_manage");
            permissions.add("batch_manage");
            permissions.add("growth_record_manage");
            permissions.add("product_manage");
            permissions.add("order_manage");
            break;
        case "FARMER":
            permissions.add("user_manage");
            permissions.add("batch_manage");
            permissions.add("growth_record_manage");
            permissions.add("product_manage");
            permissions.add("order_manage");
            break;
        case "OPERATOR":
            permissions.add("product_manage");
            permissions.add("order_manage");
            permissions.add("growth_record_manage");
            break;
        case "CUSTOMER":  // ✅ 新增
            permissions.add("order_manage");  // 顾客只能管理自己的订单
            permissions.add("product_view");  // 顾客可以查看商品
            break;
    }

    return permissions;
}
```

**A:** 这是正常的，CUSTOMER 角色权限有限：
