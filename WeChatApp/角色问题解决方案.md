# 角色问题解决方案

## 问题描述

注册时报错：`"无效的角色类型"`

## 原因分析

后端 `UserServiceImpl.java` 中的 `isValidRole()` 方法只验证三个角色：
- `SUPER_ADMIN` - 超级管理员
- `FARMER` - 农户
- `OPERATOR` - 操作员

但没有 `CUSTOMER`（顾客）角色。

```java
private boolean isValidRole(String role) {
    return "SUPER_ADMIN".equals(role) || "FARMER".equals(role) || "OPERATOR".equals(role);
}
```

---

## 解决方案

### 方案1：修改后端支持 CUSTOMER 角色（推荐）✅

修改后端文件：`Backend/xichang-interface/src/main/java/org/xingchang/xichanginterface/service/impl/UserServiceImpl.java`

```java
/**
 * 验证角色是否有效
 */
private boolean isValidRole(String role) {
    return "SUPER_ADMIN".equals(role) 
        || "FARMER".equals(role) 
        || "OPERATOR".equals(role)
        || "CUSTOMER".equals(role);  // 添加这一行
}
```

同时更新 `RegisterRequest.java` 的注释：

```java
private String role; // 可选值：SUPER_ADMIN(超级管理员)、FARMER(农户)、OPERATOR(操作员)、CUSTOMER(顾客)
```

然后重启后端服务。

---

### 方案2：小程序使用 FARMER 角色（临时方案）

修改小程序注册代码，使用 `FARMER` 角色：

```typescript
// WeChatApp/miniprogram/pages/register/register.ts
await register({
  username: phone,
  password: password,
  realName: realName,
  phone: phone,
  role: 'FARMER'  // 临时使用 FARMER 角色
});
```

**缺点：** 语义不正确，小程序用户应该是顾客而不是农户。

---

### 方案3：不发送 role 字段，后端设置默认值

修改后端，如果没有提供 role，默认设置为某个角色：

```java
// UserServiceImpl.java register() 方法中
if (request.getRole() == null || request.getRole().isEmpty()) {
    request.setRole("FARMER");  // 或其他默认角色
}
```

**缺点：** 需要修改后端逻辑。

## 推荐实施步骤

### 第1步：修改后端代码

1. 打开文件：`Backend/xichang-interface/src/main/java/org/xingchang/xichanginterface/service/impl/UserServiceImpl.java`

2. 找到 `isValidRole` 方法（大约在第 169 行）

3. 修改为：
```java
/**
 * 验证角色是否有效
 */
private boolean isValidRole(String role) {
    return "SUPER_ADMIN".equals(role) 
        || "FARMER".equals(role) 
        || "OPERATOR".equals(role)
        || "CUSTOMER".equals(role);
}
```

4. 找到 `getUserPermissions` 方法，添加 CUSTOMER 的权限：
```java
private List<String> getUserPermissions(String role) {
    List<String> permissions = new ArrayList<>();

    switch (role) {
        case "SUPER_ADMIN":
            permissions.add("user_manage");
            permissions.add("batch_manage");
            permissions.add("growth_record_manage");
            permissions.add("product_manage");
            permissions.add("order_manage");
            break;
        case "FARMER":
            permissions.add("user_manage");
            permissions.add("batch_manage");
            permissions.add("growth_record_manage");
            permissions.add("product_manage");
            permissions.add("order_manage");
            break;
        case "OPERATOR":
            permissions.add("product_manage");
            permissions.add("order_manage");
            permissions.add("growth_record_manage");
            break;
        case "CUSTOMER":  // 添加这个 case
            permissions.add("order_manage");  // 顾客只能管理自己的订单
            break;
    }

    return permissions;
}
```

### 第2步：更新 DTO 注释

打开文件：`Backend/xichang-interface/src/main/java/org/xingchang/xichanginterface/dto/RegisterRequest.java`

修改注释：
```java
private String role; // 可选值：SUPER_ADMIN(超级管理员)、FARMER(农户)、OPERATOR(操作员)、CUSTOMER(顾客)
```

### 第3步：重启后端服务

```bash
cd Backend/xichang-interface
```

### 第4步：恢复小程序代码

### 第5步：测试注册功能
