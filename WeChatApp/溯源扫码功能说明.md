# 农产品溯源扫码功能完整说明

## 功能概述

实现了完整的农产品溯源扫码验证功能，用户可以通过扫描二维码或手动输入批次号来查询产品的完整溯源信息，包括批次详情、生长记录和区块链验证信息。

---

## 一、功能特性

### 1. 多种查询方式
- **扫码查询**：使用微信扫一扫功能，扫描产品上的二维码
- **手动输入**：直接输入批次号进行查询
- **URL跳转**：支持通过URL参数直接跳转到溯源详情

### 2. 完整溯源信息展示
- **批次信息**：产品名称、批次号、农户信息、农场信息、种植收获时间、产量等
- **生长记录**：时间轴展示完整的生长过程，包括温度、湿度、天气、病虫害防治、施肥、灌溉等
- **区块链验证**：显示数据是否上链、交易哈希、上链时间等

### 3. 用户友好的界面
- 渐变色背景设计
- 标签页切换浏览不同信息
- 时间轴展示生长记录
- 图片预览功能
- 区块链验证状态可视化

@Service
public class QRCodeService {
    // 生成Base64格式的二维码图片
    public String generateQRCodeBase64(String content, int width, int height)

    public String generateBatchQRCode(String batchNumber)

#### 3. 溯源控制器接口（TraceController.java）

**查询溯源信息**
```
GET /api/trace/batch/{batchNumber}
```
返回：批次信息、生长记录列表、区块链验证信息

**生成二维码**
```
GET /api/trace/qrcode/{batchNumber}
```
返回：Base64格式的二维码图片

**验证交易哈希**
```
GET /api/trace/verify/{txHash}
```
返回：区块链验证结果

## 三、使用流程

### 场景1：扫码查询（推荐）

1. **生成二维码**
   - 农户或管理员在后台管理系统中查看批次详情
   - 系统调用 `/api/trace/qrcode/{batchNumber}` 生成二维码
   - 将二维码打印在产品包装上

2. **用户扫码**
   - 打开小程序，进入溯源查询页面
   - 点击"扫描二维码查询"按钮
   - 使用微信扫一扫功能扫描产品上的二维码

3. **查看溯源信息**
   - 自动跳转到溯源详情页
   - 查看批次信息、生长记录、区块链验证

### 场景2：手动输入查询

1. **获取批次号**
   - 从产品包装上找到批次号（如：BATCH-20240415-001）

2. **输入查询**
   - 打开小程序溯源查询页面
   - 在输入框中输入批次号
   - 点击"查询"按钮

3. **查看溯源信息**
   - 显示完整的溯源信息

### 场景3：URL直接跳转

1. **构建URL**
   ```
   pages/trace/trace?batchNumber=BATCH-20240415-001
   ```

2. **跳转方式**
   - 从产品详情页跳转
   - 从订单详情页跳转
   - 扫描二维码自动跳转

## 四、二维码内容格式

### 方式1：小程序路径（推荐）
```
pages/trace/trace?batchNumber=BATCH-20240415-001
```
- 优点：扫码后直接在小程序内打开
- 适用：微信小程序码

### 方式2：完整URL
```
https://your-domain.com/trace?batchNumber=BATCH-20240415-001
```
- 优点：可以在浏览器中打开
- 适用：普通二维码

### 方式3：纯批次号
```
BATCH-20240415-001
```
- 优点：简单直接
- 缺点：需要用户手动打开小程序

## 六、集成到现有系统

### 1. 在产品详情页添加溯源入口

**产品详情页（product-detail.wxml）**
```xml
<view class="trace-button" bindtap="goToTrace">
  <text>查看溯源信息</text>
</view>
```

**产品详情页（product-detail.ts）**
```typescript
goToTrace() {
  const { product } = this.data;
  if (product && product.batchNumber) {
    wx.navigateTo({
      url: `/pages/trace/trace?batchNumber=${product.batchNumber}`
    });
  } else {
    wx.showToast({
      title: '该产品暂无溯源信息',
      icon: 'none'
    });
  }
}
```

### 2. 在订单详情页添加溯源入口

**订单详情页（order-detail.wxml）**
```xml
<view class="order-item" wx:for="{{order.items}}" wx:key="id">
  <text>{{item.productName}}</text>
  <view class="trace-link" data-batch="{{item.batchNumber}}" bindtap="viewTrace">
    查看溯源
  </view>
</view>
```

**订单详情页（order-detail.ts）**
```typescript
viewTrace(e: any) {
  const { batch } = e.currentTarget.dataset;
  if (batch) {
    wx.navigateTo({
      url: `/pages/trace/trace?batchNumber=${batch}`
    });
  }
}
```

### 3. 在后台管理系统中生成二维码

**批次管理页面（Vue/React）**
```typescript
async generateQRCode(batchNumber: string) {
  try {
    const response = await fetch(`/api/trace/qrcode/${batchNumber}`);
    const data = await response.json();
    
    // 显示二维码
    this.qrCodeImage = data.qrCode;
    
    // 或者下载二维码
    const link = document.createElement('a');
    link.href = data.qrCode;
    link.download = `qrcode-${batchNumber}.png`;
    link.click();
  } catch (error) {
    console.error('生成二维码失败:', error);
  }
}
```

## 八、注意事项

### 1. 权限配置

**小程序需要配置扫码权限（app.json）**
```json
{
  "permission": {
    "scope.camera": {
      "desc": "需要使用您的摄像头扫描二维码"
    }
  }
}
```

### 2. 域名配置

**需要在小程序后台配置服务器域名**
- request合法域名：`https://your-domain.com`
- uploadFile合法域名：`https://your-domain.com`
- downloadFile合法域名：`https://your-domain.com`

### 3. 二维码打印建议

- **尺寸**：建议至少 3cm x 3cm
- **容错率**：使用高容错率（H级）
- **位置**：放在产品包装显眼位置
- **说明**：添加"扫码查溯源"文字提示

### 4. 性能优化

- 二维码图片使用Base64格式，避免额外的网络请求
- 溯源信息缓存，避免重复查询
- 图片懒加载，提升页面加载速度

## 十、常见问题

### Q1: 扫码后无法跳转？
**A**: 检查二维码内容格式是否正确，确保包含正确的批次号

### Q2: 查询不到溯源信息？
**A**: 
- 检查批次号是否正确
- 确认该批次是否已创建
- 检查网络连接

### Q3: 二维码生成失败？
**A**: 
- 检查后端服务是否正常运行
- 确认ZXing依赖是否正确安装
- 查看后端日志

### Q4: 图片无法显示？
**A**: 
- 检查图片URL是否正确
- 确认图片服务器是否可访问
- 检查小程序域名配置
