### 4. API 接口 ✅

#### 接口文件
- `api/user.ts` - 用户相关接口

#### 接口定义
```typescript
// 注册接口
register(data: RegisterData): Promise<UserInfo>

// 登录接口
login(data: LoginData): Promise<UserInfo>
```

#### 请求格式
```typescript
// 注册
POST /api/register
{
  username: string,
  password: string,
  realName: string,
  phone: string,
  role: 'CUSTOMER'
}

// 登录
POST /api/login
{
  username: string,
  password: string
}
```

#### 响应处理
- 支持标准格式：`{ code, message, data }`
- 支持直接返回：`{ token, user }`
- 自动提取 token 和用户信息
- 统一错误处理

## 🔧 技术实现

### 1. 表单验证

```typescript
// 手机号验证
if (!/^1[3-9]\d{9}$/.test(phone)) {
  wx.showToast({ title: '手机号格式不正确', icon: 'none' });
  return false;
}

// 密码长度验证
if (password.length < 6 || password.length > 20) {
  wx.showToast({ title: '密码长度为6-20位', icon: 'none' });
  return false;
}

// 密码一致性验证
if (password !== confirmPassword) {
  wx.showToast({ title: '两次密码输入不一致', icon: 'none' });
  return false;
}
```

## 📱 用户流程

### 新用户注册流程
```
1. 打开小程序 → 显示登录页
2. 点击"立即注册" → 跳转注册页
3. 填写信息：
   - 真实姓名
   - 手机号
   - 密码
   - 确认密码
4. 点击"注册" → 显示加载提示
5. 注册成功 → 显示成功弹窗
6. 点击确定 → 返回登录页
7. 输入手机号和密码 → 点击登录
8. 登录成功 → 跳转首页
```

### 老用户登录流程
```
1. 打开小程序 → 显示登录页
2. 输入手机号和密码
3. 点击"登录" → 显示加载提示
4. 登录成功 → 跳转首页
5. 关闭小程序
6. 再次打开 → 直接进入首页（保持登录状态）
```
