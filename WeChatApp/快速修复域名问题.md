# 🚀 快速修复域名问题

## 问题
```
request:fail url not in domain list
```

## 解决方法（3步）

### 第1步：打开设置
在微信开发者工具中，点击右上角的 **"详情"** 按钮

### 第2步：勾选选项
在弹出的窗口中：
1. 切换到 **"本地设置"** 标签页
2. 找到并勾选：**"不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书"**

### 第3步：重新编译
点击工具栏的 **"编译"** 按钮，或按 `Ctrl + B`

---

## 完成！

现在可以正常使用 `http://localhost:8080` 进行开发了。
