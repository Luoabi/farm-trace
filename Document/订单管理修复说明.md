# 订单管理修复说明

## 问题描述
hotai前端管理系统中的订单管理页面不显示数据。

## 问题原因

### 1. API调用方法名不匹配
- **问题**：前端调用 `orderAPI.getOrderListByFarmer()` 但API文件中定义的是 `orderAPI.getOrdersByFarmer()`
- **位置**：`App/Counter/hotai/src/views/OrderManagement.vue`
- **修复**：统一使用 `getOrdersByFarmer()`

### 2. 订单状态映射不一致
- **问题**：前端使用数字状态 1-4，后端使用字符串状态 '0'-'4'
- **后端状态**：
  - '0' - 待支付
  - '1' - 待发货（已支付）
  - '2' - 待收货（已发货）
  - '3' - 已完成
  - '4' - 已取消
- **修复**：前端改为使用字符串状态 '0'-'4'

### 3. 后端缺少农户订单查询方法
- **问题**：OrderMapper中没有 `findByFarmerId()` 方法
- **影响**：农户无法查看自己的订单
- **修复**：
  - 在 `OrderMapper.java` 中添加 `findByFarmerId()` 方法声明
  - 在 `OrderMapper.xml` 中添加对应的SQL查询
  - 在 `OrderServiceImpl.java` 中实现查询逻辑

### 4. 用户角色判断不完整
- **问题**：只判断 `userRole === '超级管理员'`，但数据库中可能存储为 'ADMIN'
- **修复**：添加 `userRole === 'ADMIN'` 的判断

### 5. 查询参数构建问题
- **问题**：直接使用 `...searchForm` 展开，包含了不必要的字段
- **修复**：只传递必要的 `keyword` 参数

## 数据权限说明

### 超级管理员（ADMIN）
- 可以查看所有订单
- 调用接口：`POST /api/order/list`

### 农户（FARMER）
- 只能查看自己的订单（farmer_id = 当前用户ID）
- 调用接口：`POST /api/order/list-by-farmer?farmerId={farmerId}`

### 客户（CUSTOMER）
- 只能查看自己的订单（customer_id = 当前用户ID）
- 调用接口：`POST /api/order/list-by-customer?customerId={customerId}`

## 注意事项

1. **订单状态一致性**
   - 前后端必须使用相同的状态值（字符串 '0'-'4'）
   - 数据库中存储的也是字符串类型

2. **用户信息获取**
   - 确保 localStorage 中有正确的 userInfo
   - 包含 id 和 role 字段

3. **API参数顺序**
   - `getOrdersByFarmer(params, farmerId)` - 参数顺序很重要
   - params 在前，farmerId 在后

4. **分页处理**
   - 当前使用内存分页（查询所有后再分页）
   - 生产环境建议在SQL层面实现分页
