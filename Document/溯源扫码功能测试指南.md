**方式2：使用HTML测试页面**

创建 `test-qrcode.html`：
```html
<!DOCTYPE html>
<html>
<head>
  <title>二维码生成测试</title>
  <style>
    body {
      font-family: Arial, sans-serif;

      color: white;
      border: none;
      cursor: pointer;
    }
    #qrcode {
      margin-top: 20px;
      text-align: center;
    }
    #qrcode img {
      max-width: 400px;
      border: 2px solid #ddd;
      padding: 10px;
    }
  </style>
</head>
<body>
  <h1>批次溯源二维码生成</h1>
  
  <div class="input-group">
    <input type="text" id="batchNumber" placeholder="请输入批次号" value="BATCH-20240415-001">
    <button onclick="generateQRCode()">生成二维码</button>
  </div>

  <div id="qrcode"></div>

  <script>
    async function generateQRCode() {
      const batchNumber = document.getElementById('batchNumber').value;
      
      if (!batchNumber) {
        alert('请输入批次号');
        return;
      }

      try {
        const response = await fetch(`http://localhost:8080/api/trace/qrcode/${batchNumber}`);
        const data = await response.json();
        
        document.getElementById('qrcode').innerHTML = `
          <h3>批次号: ${data.batchNumber}</h3>
          <img src="${data.qrCode}" alt="二维码">
          <p>扫码查看产品溯源信息</p>
          <button onclick="downloadQRCode('${data.qrCode}', '${data.batchNumber}')">下载二维码</button>
        `;
      } catch (error) {
        alert('生成失败: ' + error.message);
      }
    }

    function downloadQRCode(dataUrl, batchNumber) {
      const link = document.createElement('a');
      link.href = dataUrl;
      link.download = `qrcode-${batchNumber}.png`;
      link.click();
    }
  </script>
</body>
</html>
```

## 五、常见问题排查

### 问题1：二维码生成失败

**症状**：调用接口返回500错误

**排查步骤**：
1. 检查Maven依赖是否正确安装
   ```bash
   mvn dependency:tree | grep zxing
   ```

2. 查看后端日志
   ```bash
   tail -f logs/spring.log
   ```

3. 验证批次是否存在
   ```sql
   SELECT * FROM batch WHERE batch_number = 'xxx';
   ```

### 问题2：小程序扫码无反应

**症状**：点击扫码按钮没有反应

**排查步骤**：
1. 检查小程序权限配置（app.json）
2. 查看控制台错误信息
3. 确认是否在真机上测试（开发工具扫码功能有限）

### 问题3：溯源信息显示不完整

**症状**：部分信息为空或undefined

**排查步骤**：
1. 检查后端返回的数据结构
2. 查看小程序控制台日志
3. 验证数据库中的数据是否完整

### 问题4：图片无法显示

**症状**：生长记录中的图片不显示

**排查步骤**：
1. 检查图片URL是否正确
2. 确认小程序域名配置
3. 验证图片服务器是否可访问
