# 生长记录字段更新说明

## 📋 问题分析

前端 `GrowthRecordManagement.vue` 使用了以下字段，但数据库中不存在：

1. **生长阶段** (`growthStage`) - 用于标识：发芽期、幼苗期、生长期、成熟期
2. **生长状况** (`condition` / `growthCondition`) - 用于标识：良好、一般、较差、异常

## ✅ 已完成的修改

### 1. 数据库表结构更新

**文件：** `Backend/xichang-interface/src/main/resources/init.sql`

添加了两个新字段：
```sql
`growth_stage` VARCHAR(20) COMMENT '生长阶段：发芽期、幼苗期、生长期、成熟期',
`growth_condition` VARCHAR(20) COMMENT '生长状况：良好、一般、较差、异常',
```

**位置：** 在 `farmer_id` 字段之后，`record_time` 字段之前

### 2. 数据库迁移脚本

**文件：** `Backend/xichang-interface/src/main/resources/db/migration/add_growth_stage_fields.sql`

用于已有数据库的升级：
```sql
ALTER TABLE `growth_record` 
ADD COLUMN `growth_stage` VARCHAR(20) COMMENT '生长阶段：发芽期、幼苗期、生长期、成熟期' AFTER `farmer_id`,
ADD COLUMN `growth_condition` VARCHAR(20) COMMENT '生长状况：良好、一般、较差、异常' AFTER `growth_stage`;

-- 为已有数据设置默认值
UPDATE `growth_record` SET `growth_stage` = '生长期' WHERE `growth_stage` IS NULL;
UPDATE `growth_record` SET `growth_condition` = '良好' WHERE `growth_condition` IS NULL;
```

### 3. Java 模型更新

**文件：** `Backend/xichang-interface/src/main/java/org/xingchang/xichanginterface/model/GrowthRecord.java`

添加字段：
```java
private String growthStage; // 生长阶段：发芽期、幼苗期、生长期、成熟期
private String growthCondition; // 生长状况：良好、一般、较差、异常
```

### 4. DTO 更新

**文件：** 
- `Backend/xichang-interface/src/main/java/org/xingchang/xichanginterface/dto/GrowthRecordRequest.java`
- `Backend/xichang-interface/src/main/java/org/xingchang/xichanginterface/dto/GrowthRecordResponse.java`

两个 DTO 都添加了相同的字段。

### 5. MyBatis 映射更新

**文件：** `Backend/xichang-interface/src/main/resources/mapper/GrowthRecordMapper.xml`

更新了：
- `<resultMap>` - 添加字段映射
- `<insert>` - 添加插入字段
- `<update>` - 添加更新字段

### 6. 示例数据更新

**文件：** `Backend/xichang-interface/src/main/resources/init.sql`

更新了 INSERT 语句，为所有示例数据添加了 `growth_stage` 和 `growth_condition` 值。

## 🎯 字段取值说明

### 生长阶段 (growth_stage)
- **发芽期** - 种子萌发阶段
- **幼苗期** - 幼苗生长阶段
- **生长期** - 快速生长阶段
- **成熟期** - 果实成熟阶段

### 生长状况 (growth_condition)
- **良好** - 生长健康，无异常
- **一般** - 生长正常，有轻微问题
- **较差** - 生长缓慢或有明显问题
- **异常** - 出现严重病虫害或其他异常情况

## 📝 使用步骤

### 对于新数据库：
直接运行 `init.sql` 即可，表结构已包含新字段。

### 对于已有数据库：
1. 运行迁移脚本：
   ```bash
   mysql -u username -p database_name < Backend/xichang-interface/src/main/resources/db/migration/add_growth_stage_fields.sql
   ```

2. 重启后端服务

3. 前端无需修改，已经在使用这些字段

## ⚠️ 注意事项

1. 前端使用的字段名是 `condition`，但后端数据库和模型使用 `growthCondition`，需要确保前端传参时使用正确的字段名
2. 如果前端已经有数据，运行迁移脚本后会自动设置默认值（生长期 + 良好）
3. 建议在前端表单中将这两个字段设为必填项
