## 🎯 核心特性

### 1. 双模式支持
```properties
# 模拟模式（默认）- 适合开发
blockchain.enabled=false

# 真实模式 - 适合演示和生产
blockchain.enabled=true
```

### 2. 混合存证架构
- **核心数据哈希** → 上链存储（不可篡改）
- **业务详细数据** → 本地数据库（高效查询）
- **最佳实践**：兼顾可信性和经济性

### 3. 智能合约功能
```solidity
// 存储数据哈希
storeHash(dataId, hash)

// 查询上链时间
getTimestamp(dataId)

// 验证数据完整性
verifyHash(dataId, hash)
```

### 4. 自动上链流程
```
创建批次/生长记录
    ↓
计算 SHA-256 哈希
    ↓
调用智能合约存储
    ↓
返回交易哈希
    ↓
保存到数据库
```
