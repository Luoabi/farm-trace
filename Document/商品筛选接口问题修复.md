# 商品筛选接口问题修复

## 🐛 问题描述

商品管理的筛选功能不工作，无法按商品名称、分类、状态进行筛选。

## 🔍 问题原因

### 1. 字段名不匹配

**前端发送：**
```javascript
{
  name: '葡萄',      // ❌ 后端不认识
  category: '水果',  // ⚠️ 后端只在 keyword 中模糊搜索
  status: '上架'     // ❌ 应该是数字 1 或 0
}
```

**后端期望：**
```java
{
  keyword: '葡萄',   // ✅ 用于模糊搜索
  category: '水果',  // ❌ 原来不支持单独筛选
  status: 1          // ✅ 数字类型
}
```

### 2. 后端 SQL 不支持分类精确筛选

原来的 SQL 只支持在 `keyword` 中模糊搜索分类，不支持精确筛选。

## ✅ 修复方案

## 🎯 修复后的筛选逻辑

### 1. 关键词搜索（keyword）
模糊搜索以下字段：
- 商品名称 (product_name)
- 商品编号 (product_code)
- 产地 (production_place)

### 2. 分类筛选（category）
精确匹配商品分类：
- 蔬菜
- 水果
- 粮油
- 其他

### 3. 状态筛选（status）
精确匹配商品状态：
- 1 = 上架
- 0 = 下架

## 📝 使用示例

### 前端调用
```javascript
// 搜索"葡萄"，分类为"水果"，状态为"上架"
const response = await productAPI.getProductListByFarmer(farmerId, {
  page: 1,
  pageSize: 10,
  keyword: '葡萄',    // 模糊搜索
  category: '水果',   // 精确筛选
  status: '1'         // 精确筛选（上架）
});
```

### 后端 SQL 执行
```sql
SELECT * FROM product 
WHERE farmer_id = 'user002'
  AND (product_name LIKE '%葡萄%' 
       OR product_code LIKE '%葡萄%'
       OR production_place LIKE '%葡萄%')
  AND category = '水果'
  AND status = 1
ORDER BY create_time DESC
LIMIT 0, 10;
```
