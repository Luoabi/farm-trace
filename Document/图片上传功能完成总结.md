
## 🚀 使用示例

### 添加商品时上传图片

```javascript
// 1. 用户选择图片
<el-upload 
  :on-change="handleMainImageChange"
  accept="image/*"
/>

// 2. 自动上传
const handleMainImageChange = async (uploadFile) => {
  const response = await uploadAPI.uploadImage(uploadFile.raw);
  productForm.imageUrl = response.url;
}

// 3. 保存商品
const submitData = {
  productName: '西昌葡萄',
  imageUrl: productForm.imageUrl,  // 图片 URL
  ...
}
```

### 查看商品图片

```vue
<el-image 
  :src="product.imageUrl" 
  fit="cover"
/>
```
