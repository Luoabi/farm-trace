## 🔄 工作流程

### 数据上链流程
```
用户创建批次/生长记录
    ↓
系统计算 SHA-256 哈希
    ↓
判断模式（真实/模拟）
    ↓
真实模式：调用智能合约 storeHash()
模拟模式：生成模拟哈希
    ↓
返回交易哈希
    ↓
保存到数据库（txHash, chainStatus, chainTime）
    ↓
完成
```

### 溯源查询流程
```
用户扫码/输入批次号
    ↓
查询数据库获取批次信息
    ↓
获取交易哈希（txHash）
    ↓
判断模式（真实/模拟）
    ↓
真实模式：查询区块链验证交易
模拟模式：格式验证
    ↓
返回溯源信息 + 区块链验证结果
    ↓
展示给用户
```

## 💡 技术亮点

### 1. 混合存证架构
```
核心数据（哈希）→ 区块链（不可篡改）
详细数据 → 本地数据库（高效查询）
```

**优势：**
- ✅ 保证数据不可篡改
- ✅ 降低存储成本
- ✅ 提高查询效率
- ✅ 符合实际应用场景

### 2. 智能合约设计
```solidity
contract AgriTrace {
    // 存储：数据ID → 哈希值
    mapping(string => bytes32) public dataHashes;
    
    // 存储：数据ID → 上链时间
    mapping(string => uint256) public timestamps;
    
    // 上链方法
    function storeHash(string dataId, bytes32 hash)
    
    // 查询时间
    function getTimestamp(string dataId)
    
    // 验证哈希
    function verifyHash(string dataId, bytes32 hash)
}
```

**特点：**
- ✅ 简洁高效
- ✅ Gas 消耗低
- ✅ 功能完整
- ✅ 易于维护

### 3. 双模式架构
```java
if (blockchainEnabled) {
    // 真实区块链
    return uploadToRealBlockchain(dataId);
} else {
    // 模拟模式
    return uploadToMockBlockchain(dataId);
}
```

**优势：**
- ✅ 开发时使用模拟模式（快速）
- ✅ 演示时使用真实模式（可信）
- ✅ 无需修改业务代码
- ✅ 配置即可切换
