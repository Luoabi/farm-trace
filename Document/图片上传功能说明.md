# 图片上传功能说明

## ✅ 已完成的功能

### 后端实现

#### 1. 文件上传控制器
**文件**: `FileUploadController.java`

**功能：**
- ✅ 单个图片上传
- ✅ 批量图片上传（最多10个）
- ✅ 文件删除
- ✅ 文件类型验证（JPG/PNG/GIF/WEBP）
- ✅ 文件大小限制（10MB）
- ✅ 自动生成唯一文件名
- ✅ 按日期分类存储（yyyy/MM/dd）

**接口：**
```
POST /api/upload/image        - 上传单个图片
POST /api/upload/images       - 批量上传图片
DELETE /api/upload/file       - 删除文件
```

#### 2. 静态资源配置
**文件**: `WebMvcConfig.java`

**功能：**
- ✅ 配置静态资源访问路径
- ✅ 支持通过 URL 访问上传的文件

**访问路径：**
```
http://localhost:8080/uploads/images/2025/01/10/文件名.jpg
```

#### 3. 配置文件
**文件**: `application.properties`

**配置项：**
```properties
# 文件上传路径
file.upload.path=uploads

# 文件访问URL前缀
file.access.url=http://localhost:8080/uploads

# 单个文件最大大小（10MB）
spring.servlet.multipart.max-file-size=10MB

# 请求最大大小（50MB）
spring.servlet.multipart.max-request-size=50MB
```

## 🚀 使用方式

### 1. 添加商品时上传图片

**步骤：**
1. 点击"添加商品"按钮
2. 填写商品信息
3. 在"商品图片"区域点击上传框
4. 选择图片文件（JPG/PNG/GIF/WEBP）
5. 图片自动上传到服务器
6. 看到"✓ 图片已上传"提示
7. 点击"保存"创建商品

**限制：**
- 支持格式：JPG、PNG、GIF、WEBP
- 文件大小：最大 10MB
- 数量限制：每个商品 1 张主图
- 建议尺寸：800x800 像素

### 2. 编辑商品时更换图片

**步骤：**
1. 点击商品的"编辑"按钮
2. 看到已有图片的预览
3. 点击删除图标移除旧图片
4. 上传新图片
5. 点击"保存"更新商品

### 3. 查看商品图片

**步骤：**
1. 点击商品的"查看"按钮
2. 在详情对话框中查看商品图片
3. 图片以 200x200 尺寸显示

## 🔧 配置说明

### 修改上传路径

编辑 `application.properties`：

```properties
# 使用相对路径（项目根目录下）
file.upload.path=uploads

# 或使用绝对路径
file.upload.path=/var/www/uploads
```

### 修改访问 URL

```properties
# 开发环境
file.access.url=http://localhost:8080/uploads

# 生产环境
file.access.url=https://yourdomain.com/uploads
```

### 修改文件大小限制

```properties
# 单个文件最大 20MB
spring.servlet.multipart.max-file-size=20MB

# 请求最大 100MB
spring.servlet.multipart.max-request-size=100MB
```

## 🐛 常见问题

### 1. 上传失败：文件太大

**问题：** 提示"文件大小不能超过10MB"

**解决：**
- 压缩图片后再上传
- 或修改配置增加限制：
  ```properties
  spring.servlet.multipart.max-file-size=20MB
  ```

### 2. 上传失败：不支持的格式

**问题：** 提示"只支持 JPG、PNG、GIF、WEBP 格式的图片"

**解决：**
- 使用支持的图片格式
- 或在后端添加更多格式支持

### 3. 图片无法访问

**问题：** 上传成功但无法查看图片

**解决：**
1. 检查 `uploads` 目录是否存在
2. 检查文件权限
3. 检查 `file.access.url` 配置是否正确
4. 确认 `WebMvcConfig` 配置生效

### 4. 跨域问题

**问题：** 前端无法上传文件

**解决：**
- 确认 `FileUploadController` 中的 `@CrossOrigin` 配置
- 检查前端请求的域名是否在允许列表中
