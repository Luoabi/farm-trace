# 图片上传功能快速测试指南

## 🚀 快速测试（5分钟）

### 第一步：启动后端（1分钟）

```bash
cd App/Backend/xichang-interface
mvn spring-boot:run
```

等待启动完成，看到：
```
Started XichangInterfaceApplication in X.XXX seconds
```

### 第二步：启动前端（1分钟）

```bash
cd App/Counter/hotai
npm run dev
```

访问：http://localhost:5173

### 第三步：测试上传（3分钟）

#### 1. 登录系统
- 使用农户或超级管理员账号登录

#### 2. 进入商品管理
- 点击左侧菜单"商品管理"

#### 3. 添加商品
- 点击"添加商品"按钮
- 填写基本信息：
  ```
  商品编号：TEST001
  商品名称：测试商品
  商品分类：水果
  参考价格：10
  单位：kg
  包装规格：5kg/箱
  产地：四川西昌
  ```

#### 4. 上传图片
- 在"商品图片"区域点击上传框
- 选择一张图片（JPG/PNG）
- 等待上传完成
- 看到"✓ 图片已上传"提示

#### 5. 保存商品
- 点击"保存"按钮
- 看到"商品创建成功"提示

#### 6. 验证图片
- 在商品列表中找到刚创建的商品
- 点击"查看"按钮
- 确认图片正常显示

## 🔍 问题排查

### 问题1：上传失败

**现象：** 点击上传后提示失败

**检查：**
```bash
# 1. 检查后端是否启动
curl http://localhost:8080/api/upload/image

# 2. 检查 uploads 目录是否存在
ls -la uploads/

# 3. 查看后端日志
# 看是否有错误信息
```

**解决：**
- 确保后端正常运行
- 创建 uploads 目录：`mkdir -p uploads/images`
- 检查文件权限

### 问题2：图片无法显示

**现象：** 上传成功但图片不显示

**检查：**
```bash
# 1. 检查图片文件是否存在
ls -la uploads/images/2025/01/10/

# 2. 测试图片 URL
curl http://localhost:8080/uploads/images/2025/01/10/文件名.jpg

# 3. 检查浏览器控制台
# 看是否有 404 错误
```

**解决：**
- 确认 `WebMvcConfig` 配置正确
- 检查 `file.access.url` 配置
- 重启后端服务

### 问题3：跨域错误

**现象：** 浏览器控制台显示 CORS 错误

**检查：**
```javascript
// 浏览器控制台错误信息
Access to XMLHttpRequest at 'http://localhost:8080/api/upload/image' 
from origin 'http://localhost:5173' has been blocked by CORS policy
```

**解决：**
- 确认 `FileUploadController` 中有 `@CrossOrigin` 注解
- 检查允许的域名是否包含 `http://localhost:5173`
