# 收货地址管理实现说明

## 一、功能概述

收货地址管理模块提供完整的 CRUD 功能，支持：
- 创建收货地址
- 查询地址列表
- 查询地址详情
- 更新地址信息
- 删除地址
- 设置默认地址
- 获取默认地址

---

## 二、数据库设计

### 表结构：user_address

```sql
CREATE TABLE user_address (
    id VARCHAR(50) PRIMARY KEY COMMENT '地址ID',
    user_id VARCHAR(50) NOT NULL COMMENT '用户ID',
    receiver_name VARCHAR(50) NOT NULL COMMENT '收货人姓名',
    receiver_phone VARCHAR(20) NOT NULL COMMENT '收货人电话',
    province VARCHAR(50) NOT NULL COMMENT '省份',
    city VARCHAR(50) NOT NULL COMMENT '城市',
    district VARCHAR(50) NOT NULL COMMENT '区/县',
    detail_address VARCHAR(200) NOT NULL COMMENT '详细地址',
    is_default TINYINT DEFAULT 0 COMMENT '是否默认地址：0-否，1-是',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    INDEX idx_user_id (user_id),
    INDEX idx_is_default (is_default)
);
```

### 字段说明

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | VARCHAR(50) | 地址ID，格式：addr001, addr002... |
| user_id | VARCHAR(50) | 用户ID |
| receiver_name | VARCHAR(50) | 收货人姓名 |
| receiver_phone | VARCHAR(20) | 收货人电话 |
| province | VARCHAR(50) | 省份 |
| city | VARCHAR(50) | 城市 |
| district | VARCHAR(50) | 区/县 |
| detail_address | VARCHAR(200) | 详细地址 |
| is_default | TINYINT | 是否默认地址：0-否，1-是 |
| create_time | DATETIME | 创建时间 |
| update_time | DATETIME | 更新时间 |

## 四、业务逻辑

### 1. 创建地址
- 自动生成地址ID（addr001, addr002...）
- 如果是用户的第一个地址，自动设置为默认地址
- 如果设置为默认地址，先取消该用户的其他默认地址
- 返回创建的地址信息（包含完整地址）

### 2. 查询地址列表
- 按默认地址优先、创建时间倒序排列
- 返回该用户的所有地址

### 3. 获取默认地址
- 返回用户的默认地址
- 如果没有默认地址，返回第一个地址
- 如果没有任何地址，返回 null

### 4. 更新地址
- 验证地址是否存在
- 如果设置为默认地址，先取消该用户的其他默认地址
- 更新地址信息

### 5. 删除地址
- 验证地址是否存在
- 如果删除的是默认地址，自动将第一个地址设置为默认
- 删除地址

### 6. 设置默认地址
- 验证地址是否存在
- 验证地址是否属于该用户
- 取消该用户的其他默认地址
- 设置为默认地址

## 五、前端使用示例

### 1. 获取地址列表

```javascript
import { addressAPI } from '@/api/modules/address';

const loadAddressList = async () => {
  try {
    const userId = JSON.parse(localStorage.getItem('userInfo')).id;
    const addressList = await addressAPI.getAddressList(userId);
    console.log('地址列表:', addressList);
  } catch (error) {
    console.error('获取地址列表失败:', error);
  }
};
```

### 2. 创建地址

```javascript
import { addressAPI } from '@/api/modules/address';
import { ElMessage } from 'element-plus';

const createAddress = async () => {
  try {
    const userId = JSON.parse(localStorage.getItem('userInfo')).id;
    const addressData = {
      userId: userId,
      receiverName: '张三',
      receiverPhone: '13800138000',
      province: '四川省',
      city: '成都市',
      district: '高新区',
      detailAddress: '天府大道123号',
```


### 4. 删除地址

```javascript
import { addressAPI } from '@/api/modules/address';
import { ElMessage, ElMessageBox } from 'element-plus';

const deleteAddress = async (addressId) => {
  try {
    await ElMessageBox.confirm('确定要删除这个地址吗？', '提示', {
```

## 六、Vue 组件示例

### 地址管理页面

```vue
<template>
  <div class="address-management">

        </template>
      </el-table-column>
      <el-table-column label="操作" width="200">
        <template #default="{ row }">
          <el-button type="link" size="small" @click="handleEdit(row)">编辑</el-button>
          <el-button 
            type="link" 
            size="small" 
            @click="handleSetDefault(row)"
            v-if="row.isDefault !== 1"
          >
            设为默认
          </el-button>
          <el-button type="link" size="small" @click="handleDelete(row)">删除</el-button>
        </template>
      </el-table-column>
    </el-table>
    
    <!-- 地址表单对话框 -->
    <el-dialog 
      v-model="dialogVisible" 
      :title="isEdit ? '编辑地址' : '添加地址'"
      width="500px"
    >
      <el-form :model="addressForm" label-width="100px">
        <el-form-item label="收货人">
          <el-input v-model="addressForm.receiverName" />
        </el-form-item>
        <el-form-item label="电话">
          <el-input v-model="addressForm.receiverPhone" />
        </el-form-item>
        <el-form-item label="省份">
          <el-input v-model="addressForm.province" />
        </el-form-item>
        <el-form-item label="城市">
          <el-input v-model="addressForm.city" />
        </el-form-item>
        <el-form-item label="区/县">
          <el-input v-model="addressForm.district" />
        </el-form-item>
        <el-form-item label="详细地址">
          <el-input v-model="addressForm.detailAddress" type="textarea" />
        </el-form-item>
        <el-form-item label="设为默认">
          <el-switch v-model="addressForm.isDefault" :active-value="1" :inactive-value="0" />
        </el-form-item>
      </el-form>
      <template #footer>
        <el-button @click="dialogVisible = false">取消</el-button>
        <el-button type="primary" @click="handleSave">保存</el-button>
      </template>
    </el-dialog>
  </div>
</template>

<script setup>
import { ref, reactive, onMounted } from 'vue';
import { ElMessage, ElMessageBox } from 'element-plus';
import { addressAPI } from '@/api/modules/address';

const addressList = ref([]);
const dialogVisible = ref(false);
const isEdit = ref(false);

const addressForm = reactive({
  id: '',
  userId: '',
  receiverName: '',
  receiverPhone: '',
  province: '',
  city: '',
  district: '',
  detailAddress: '',
  isDefault: 0
});

// 获取用户ID
const getUserId = () => {
  const userInfo = JSON.parse(localStorage.getItem('userInfo'));
  return userInfo?.id || '';
};

// 加载地址列表
const loadAddressList = async () => {
  try {
    const userId = getUserId();
    addressList.value = await addressAPI.getAddressList(userId);
  } catch (error) {
    console.error('获取地址列表失败:', error);
    ElMessage.error('获取地址列表失败');
  }
};

// 添加地址
const handleAdd = () => {
  isEdit.value = false;
  Object.assign(addressForm, {
    id: '',
    userId: getUserId(),
    receiverName: '',
    receiverPhone: '',
    province: '',
    city: '',
    district: '',
    detailAddress: '',
    isDefault: 0
  });
  dialogVisible.value = true;
};

// 编辑地址
const handleEdit = (row) => {
  isEdit.value = true;
  Object.assign(addressForm, row);
  dialogVisible.value = true;
};

// 保存地址
const handleSave = async () => {
  try {
    if (isEdit.value) {
      await addressAPI.updateAddress(addressForm.id, addressForm);
      ElMessage.success('地址更新成功');
    } else {
      await addressAPI.createAddress(addressForm);
      ElMessage.success('地址添加成功');
    }
    dialogVisible.value = false;
    loadAddressList();
  } catch (error) {
    console.error('保存地址失败:', error);
    ElMessage.error('保存失败');
  }
};

// 删除地址
const handleDelete = async (row) => {
  try {
    await ElMessageBox.confirm('确定要删除这个地址吗？', '提示', {
      confirmButtonText: '确定',
      cancelButtonText: '取消',
      type: 'warning'
    });
    
    await addressAPI.deleteAddress(row.id);
    ElMessage.success('地址删除成功');
    loadAddressList();
  } catch (error) {
    if (error !== 'cancel') {
      console.error('删除地址失败:', error);
      ElMessage.error('删除失败');
    }
  }
};

// 设置默认地址
const handleSetDefault = async (row) => {
  try {
    const userId = getUserId();
    await addressAPI.setDefaultAddress(row.id, userId);
    ElMessage.success('已设置为默认地址');
    loadAddressList();
  } catch (error) {
    console.error('设置默认地址失败:', error);
    ElMessage.error('设置失败');
  }
};

onMounted(() => {
  loadAddressList();
});
</script>
```

## 七、注意事项

### 1. 默认地址逻辑
- 每个用户只能有一个默认地址
- 第一个地址自动设置为默认地址
- 设置新的默认地址时，会自动取消其他默认地址
- 删除默认地址时，会自动将第一个地址设置为默认

### 2. 权限控制
- 建议添加权限验证，用户只能操作自己的地址
- 在 Service 层验证地址是否属于该用户

### 3. 数据验证
- 建议添加字段验证（手机号格式、地址长度等）
- 可以使用 JSR-303 注解进行验证

### 4. 地址选择器
- 建议集成省市区三级联动选择器
- 可以使用 Element Plus 的 Cascader 组件
