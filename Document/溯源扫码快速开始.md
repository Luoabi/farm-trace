# 溯源扫码功能 - 快速开始 🚀

## 5分钟快速体验

### 第一步：启动后端服务

```bash
cd App/Backend/xichang-interface
mvn spring-boot:run
```

等待服务启动完成（看到 "Started XichangInterfaceApplication" 提示）

### 第二步：测试二维码生成

打开浏览器访问：
```
http://localhost:8080/api/trace/qrcode/BATCH-20240415-001
```

你会看到返回的JSON数据，包含Base64格式的二维码图片。

### 第三步：启动小程序

1. 打开微信开发者工具
2. 导入项目：选择 `App/WeChatApp` 目录
3. 点击"编译"按钮

### 第四步：测试扫码功能

**方式1：手动输入测试**
1. 在小程序中找到"溯源查询"页面
2. 在输入框中输入：`BATCH-20240415-001`
3. 点击"查询"按钮
4. 查看溯源信息

**方式2：URL参数测试**
1. 在开发工具顶部地址栏输入：
   ```
   pages/trace/trace?batchNumber=BATCH-20240415-001
   ```
2. 按回车键
3. 自动显示溯源信息

**方式3：扫码测试（需要真机）**
1. 先生成二维码（见下方）
2. 点击"扫描二维码查询"
3. 扫描生成的二维码
4. 查看溯源信息

## 生成测试二维码

### 方法1：使用HTML测试页面

创建一个 `test.html` 文件：

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>二维码生成</title>
</head>
<body>
  <h1>批次二维码生成</h1>
  <input id="batch" value="BATCH-20240415-001">
  <button onclick="generate()">生成</button>
  <div id="result"></div>
  
  <script>
    async function generate() {
      const batch = document.getElementById('batch').value;
      const res = await fetch(`http://localhost:8080/api/trace/qrcode/${batch}`);
      const data = await res.json();
      document.getElementById('result').innerHTML = 
        `<img src="${data.qrCode}" style="width:300px">`;
    }
  </script>
</body>
</html>
```

用浏览器打开这个文件，点击"生成"按钮即可看到二维码。

### 方法2：使用curl命令

```bash
# 生成二维码并保存返回结果
curl http://localhost:8080/api/trace/qrcode/BATCH-20240415-001 > qrcode.json

# 查看返回的数据
cat qrcode.json
```

### 方法3：使用后台管理系统

如果你已经启动了后台管理系统（Vue项目）：

1. 访问：`http://localhost:5173/qrcode`
2. 输入批次号
3. 点击"生成二维码"
4. 可以下载、打印或复制二维码

## 常见问题

### Q: 后端启动失败？
**A**: 检查：
1. Java版本是否为17
2. MySQL是否启动
3. 数据库配置是否正确（application.yml）
4. Maven依赖是否安装完成

### Q: 小程序无法连接后端？
**A**: 检查：
1. 后端服务是否启动（端口8080）
2. 小程序中的API地址是否正确（utils/request.ts）
3. 开发工具是否勾选"不校验合法域名"

### Q: 查询不到溯源信息？
**A**: 检查：
1. 批次号是否正确
2. 数据库中是否有该批次数据
3. 后端日志是否有错误信息

### Q: 二维码生成失败？
**A**: 检查：
1. ZXing依赖是否正确安装（mvn dependency:tree | grep zxing）
2. 批次是否存在
3. 后端日志错误信息
