# 支付功能实现说明

## 功能概述

已为微信小程序添加完整的支付功能，包括：
- 订单创建后自动发起支付
- 订单列表中的"立即支付"按钮
- 订单详情页的"立即支付"按钮
- 支付成功后自动更新订单状态

## 实现方式

### 当前实现（模拟支付）

由于这是演示项目，目前使用**模拟支付**方式：
1. 用户点击"立即支付"按钮
2. 显示支付确认对话框
3. 调用后端支付接口 `/api/order/pay/{id}`
4. 后端直接将订单状态从"待支付(0)"更新为"待发货(1)"
5. 前端显示支付成功提示

### 生产环境实现（真实微信支付）

在实际生产环境中，需要接入真实的微信支付API：

#### 1. 后端改造

在 `OrderServiceImpl.payOrder()` 方法中：

```java
@Override
public OrderResponse payOrder(String id) {
    Order order = orderMapper.findById(id);
    if (order == null) {
        throw new RuntimeException("订单不存在");
    }
    
    // 检查订单状态
    if (!"0".equals(order.getOrderStatus())) {
        throw new RuntimeException("订单状态不正确，无法支付");
    }
    
    // 调用微信支付统一下单API
    WxPayUnifiedOrderRequest request = new WxPayUnifiedOrderRequest();
    request.setOutTradeNo(order.getOrderNumber());
    request.setTotalFee((int)(order.getTotalPrice() * 100)); // 单位：分
    request.setBody("西昌农产品-" + order.getProductName());
    request.setTradeType("JSAPI");
    request.setOpenid(order.getCustomerId()); // 需要获取用户的openid
    
    WxPayUnifiedOrderResult result = wxPayService.unifiedOrder(request);
    
    // 返回支付参数给前端
    Map<String, String> payParams = new HashMap<>();
    payParams.put("timeStamp", String.valueOf(System.currentTimeMillis() / 1000));
    payParams.put("nonceStr", result.getNonceStr());
    payParams.put("package", "prepay_id=" + result.getPrepayId());
    payParams.put("signType", "MD5");
    payParams.put("paySign", wxPayService.createJsapiSignature(payParams));
    
    return payParams;
}
```

#### 2. 前端改造

在小程序中调用真实的微信支付：

```typescript
async handlePayOrder() {
  try {
    wx.showLoading({ title: '发起支付...', mask: true });
    
    // 调用后端获取支付参数
    const payParams = await payOrder(order.id);
    
    wx.hideLoading();
    
    // 调用微信支付
    wx.requestPayment({
      timeStamp: payParams.timeStamp,
      nonceStr: payParams.nonceStr,
      package: payParams.package,
      signType: payParams.signType,
      paySign: payParams.paySign,
      success: (res) => {
        wx.showToast({
          title: '支付成功',
          icon: 'success'
        });
        // 刷新订单状态
        this.loadOrderDetail(order.id);
      },
      fail: (err) => {
        if (err.errMsg === 'requestPayment:fail cancel') {
          wx.showToast({
            title: '支付已取消',
            icon: 'none'
          });
        } else {
          wx.showToast({
            title: '支付失败',
            icon: 'none'
          });
        }
      }
    });
  } catch (error: any) {
    wx.hideLoading();
    wx.showToast({
      title: error.message || '支付失败',
      icon: 'none'
    });
  }
}
```

#### 3. 支付回调处理

需要在后端添加微信支付回调接口：

```java
@PostMapping("/pay/callback")
public String payCallback(@RequestBody String xmlData) {
    try {
        WxPayOrderNotifyResult result = wxPayService.parseOrderNotifyResult(xmlData);
        
        // 验证签名
        if (!wxPayService.checkSign(result)) {
            return "FAIL";
        }
        
        // 更新订单状态
        String orderNumber = result.getOutTradeNo();
        Order order = orderMapper.findByOrderNumber(orderNumber);
        
        if (order != null && "0".equals(order.getOrderStatus())) {
            orderMapper.updateStatus(order.getId(), "1"); // 更新为待发货
            order.setPaymentTime(LocalDateTime.now());
        }
        
        return "SUCCESS";
    } catch (Exception e) {
        log.error("支付回调处理失败", e);
        return "FAIL";
    }
}
```

## 支付流程

### 1. 下单后自动支付（单商品）
```
用户提交订单 → 创建订单成功 → 自动发起支付 → 支付成功 → 跳转订单详情
```

### 2. 订单列表支付
```
订单列表 → 点击"立即支付" → 确认支付金额 → 支付成功 → 刷新列表
```

### 3. 订单详情支付
```
订单详情 → 点击"立即支付" → 确认支付金额 → 支付成功 → 刷新详情
```

## 订单状态流转

```
0 (待支付) → [支付] → 1 (待发货) → [发货] → 2 (待收货) → [确认收货] → 3 (已完成)
     ↓
  [取消订单]
     ↓
  4 (已取消)
```

## 按钮显示逻辑

### 订单列表
- **待支付(0)**：显示"取消订单" + "立即支付"
- **待发货(1)**：显示"查看详情"
- **待收货(2)**：显示"确认收货" + "查看详情"
- **已完成(3)**：显示"删除订单" + "查看详情"
- **已取消(4)**：显示"删除订单" + "查看详情"

### 订单详情
- **待支付(0)**：显示"取消订单" + "立即支付"
- **待发货(1)**：显示"取消订单"
- **待收货(2)**：显示"确认收货"
- **已完成(3)**：不显示操作按钮
- **已取消(4)**：不显示操作按钮

## 注意事项

1. **当前为模拟支付**：点击支付后直接成功，无需真实付款
2. **生产环境需要**：
   - 申请微信支付商户号
   - 配置支付密钥和证书
   - 实现支付回调接口
   - 处理支付异常和退款
3. **安全性**：
   - 支付金额在后端计算，不信任前端传值
   - 验证订单状态，防止重复支付
   - 验证支付回调签名
4. **用户体验**：
   - 支付失败提供重试选项
   - 支付取消不影响订单（订单仍为待支付状态）
   - 支付成功后及时更新UI
